# ⚡ Local Peer Starter Kit v1.0

## The Philosophy: Absolute Data Sovereignty
The **Local Peer Starter Kit** is designed for the "Operator." It is not a toy; it is the seed of a professional, self-hosted intelligence environment. 

In an era of centralized AI, the only way to ensure privacy, security, and uninterrupted access to your intelligence is to **own the weights and the hardware.** This kit allows you to go from a bare-metal Linux install to a production-grade local AI stack in under 60 minutes.

---

## 🛠 The Stack
We have curated this specific combination of tools to balance **developer velocity** with **operator performance**:

| Component | Tool | Role | Why? |
| :--- | :--- | :--- | :--- |
| **Inference** | **Ollama** | LLM Backend | Minimal friction, industry-standard model management, and native GPU acceleration. |
| **Interface** | **Open WebUI** | Frontend | A comprehensive, ChatGPT-like experience with built-in user management and RAG support. |
| **Memory** | **Qdrant** | Vector Database | High-performance, production-grade vector search. Open WebUI is wired to Qdrant as its RAG vector store out of the box (`VECTOR_DB=qdrant`) instead of the embedded ChromaDB — so your knowledge base gets scalable persistence and advanced filtering from day one, and you can query the same embeddings from your own pipelines. |
| **Sovereignty** | **Local-First** | Paradigm | No telemetry, no third-party API dependencies. |
### Architecture
The stack is containerized via Docker, ensuring that your host OS remains clean and your environment is portable. All data is persisted in local volumes, meaning your intelligence persists even if the containers are wiped.

## 🚀 Quickstart

### Prerequisites
- **OS:** Ubuntu 22.04+ (Recommended)
- **Hardware:** NVIDIA GPU (RTX 3090 / 4090 recommended)
- **Software:** NVIDIA Drivers, Docker Engine, Docker Compose V2

### Deployment
1. **Clone the Kit:**
   ```bash
   git clone https://github.com/your-org/local-peer-starter-kit.git
   cd local-peer-starter-kit
   ```

2. **Run the Operator Setup:**
   ```bash
   ./setup.sh
   ```

3. **Access the Interface:**
   Navigate to `http://localhost:3000` in your browser.

4. **Initialize Intelligence:**
   Go to **Settings $\rightarrow$ Models** and pull your first model (e.g., `llama3` or `mistral`).

## ⚙️ Configuration
All environment variables are managed via the `.env` file. 

- `WEBUI_SECRET_KEY`: Auto-generated by `setup.sh` on first run. Keep it secret — changing it invalidates existing login sessions.
- `OLLAMA_PORT`: Default `11434`.
- `QDRANT_STORAGE_PATH`: Where your vector embeddings live.

## 🛡️ Data Ownership
Everything in this kit is designed for the **local-first** paradigm. 
- No telemetry is sent to third-party servers.
- Your documents stay on your disk.
- Your prompts are processed on your silicon.

**You are the admin. You are the operator. You own the data.**
